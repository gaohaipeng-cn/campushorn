# CampusHorn（校园网小喇叭）

> 轻量级校园局域网通知广播工具 / A lightweight campus LAN notification broadcast tool.

## 这是什么？

一个校园局域网内的桌面通知广播工具。教师在自己的电脑上发送通知，教室电脑全屏弹出显示。

**两个角色：**

| 角色 | 程序 | 谁用 |
|------|------|------|
| 📣 发送端 | `sender.exe` | 教师（办公电脑） |
| 📺 接收端 | `receiver.exe` | 教室（一体机/班班通电脑） |

---

## 一、准备工作（IT管理员）

### 1. 部署中转服务器

教室电脑和教师电脑可能不在同一 VLAN（比如教师 IP 是 `192.168.0.x`，教室是 `192.168.1.x`），需要通过一台 HTTP 中转服务器桥接。

- 找一台**两个 VLAN 都能访问**的电脑（或内网服务器）
- 安装 Nginx + PHP
- 将 `broadcast.php` 放到网站目录下（如 `/var/www/html/api/broadcast.php`）
- 确保 PHP 有权限读写 `broadcast.php` 同目录下的 `messages.json` 和 `classes.json`

### 2. 教室端部署

- 将 `receiver.exe` 放到每间教室的电脑上
- 首次运行会弹窗询问：
  - **班级名**（如"五年级9班"）
  - **服务器地址**（中转服务器的 IP，如 `192.168.0.x`）
- 建议设为开机自启动（拖到"启动"文件夹即可）

### 3. 教师端分发

- 将 `sender.exe` 发给每位教师
- 首次运行同样会询问**教师姓名**和**服务器地址**
- 填写后自动记住，无需重复设置

## 二、教师使用说明

### 操作步骤

1. **确认班级列表** — 左侧自动显示当前在线的教室，勾选要发送的目标
2. **输入通知内容** — 右侧文本框输入消息
3. **选择显示时长** — 5秒 / 10秒 / 15秒 / 30秒 / 60秒 / 自定义
4. **点击发送** — 选中教室的屏幕立即全屏弹出通知

### 定时发送

- 勾选"定时发送"后，设置日期和时间
- 到点自动发送，适合提前安排的通知

### 修改设置

- 点击标题栏的**教师姓名**可修改
- 点击标题栏的**服务器地址**可修改中转服务器 IP

---

## 三、教室端说明

- 教室电脑运行 `receiver.exe` 后，标题栏显示班级名
- 收到通知时，屏幕全屏显示通知内容，底部有关闭和最小化按钮
- 程序可最小化到系统托盘，后台静默运行
- 班级名和服务器地址点击标题栏即可修改

---

## 四、卸载方法

- 发送端可直接删除
- 接收端不能直接删除，要先右击系统托盘内的蓝色小喇叭图标，取消开机启动，然后再次右击图标，退出程序，最后删除“接收端.exe”
- 删除以下文件夹 C:\Users\自己账号\AppData\Local\CampusBroadcast

## 五、常见问题

**Q: 发送端看不到任何班级？**
- 确认教室电脑已运行 receiver.exe
- 确认发送端和接收端设置的**服务器地址一致**
- 确认学校网络没有阻止 PHP 服务器的访问

**Q: 教室收不到通知？**
- 检查教室电脑 receiver.exe 是否在运行
- 检查中转服务器是否正常（访问 `http://服务器IP/api/broadcast.php?action=ping` 应返回 `pong`）

**Q: 可以多个教师同时发送吗？**
- 可以。多个 sender.exe 互不干扰，PHP 服务器已做并发保护。

**Q: 更换电脑需要重新设置吗？**
- 需要。姓名、班级、服务器地址存储在各自电脑的 `config.json` 中。
